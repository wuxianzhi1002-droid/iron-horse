# 铁马驿站排班中心

手机优先的排班与请假补班网页。页面和 API 由同一个 Node.js 服务提供，SQLite 保存账号、报名、排班、审批和管理员操作记录。无需 npm 安装第三方依赖。

## 本机启动

需要 Node.js 22.13 或更新版本。PowerShell 中运行：

```powershell
npm start
```

打开 `http://localhost:3000`。首次打开会要求创建唯一的管理员账号；管理员随后可以在“成员管理”中创建同学账号。数据库会自动写入 `data/iron-horse.sqlite`。

停止服务按 `Ctrl+C`。数据库文件应定期备份；备份时先停止服务，再复制 `data/iron-horse.sqlite`。

## 手机和多人访问

在同一个 Wi-Fi/局域网内，可以在运行服务的电脑上查看本机 IP（PowerShell 执行 `ipconfig`），然后让手机访问 `http://电脑的局域网 IP:3000`。服务必须保持运行，电脑和手机需要能互相访问；Windows 防火墙可能需要允许 Node.js 接收局域网连接。

跨校区或互联网访问需要一台持续在线、能被用户访问的服务器，通常配置域名和 HTTPS。部署在 HTTPS 反向代理后，启动前设置 `COOKIE_SECURE=1`；可用 `PORT` 指定监听端口，`DB_PATH` 指定数据库文件位置。SQLite 适合当前小规模单服务使用；如果以后需要多实例、高并发或托管数据库，可迁移到 PostgreSQL。

## 安装到手机

项目包含 PWA 应用清单、铁马驿站风格图标和只缓存静态外壳的 Service Worker。正式安装需要 HTTPS；Android 可在 Chrome 菜单中选择“安装应用/添加到主屏幕”，iPhone 可在 Safari 分享菜单中选择“添加到主屏幕”。API 与个人报名/申请数据不会被离线缓存，排班变更仍需联网。

### Android 安装包

Android 原生容器由 Capacitor 构建，应用打开后连接 `capacitor.config.ts` 中配置的线上 HTTPS 服务；服务器仍需保持在线。排班系统界面由服务器提供，网页更新后 App 下次加载即可使用新版，无需为常规界面和排班功能更新重新安装 APK。只有 Android 原生容器或本地能力发生变化时才需要发布新 APK。推送 Android 工程或依赖变更会由 GitHub Actions 构建测试 APK。正式版本在 GitHub Actions 手动运行 `Publish Android Release` 并填写语义版本号（例如 `1.0.2`），或推送 `v*` 标签后构建；签名 APK 自动发布到 GitHub Releases。发布工作流需要仓库 Actions Secrets：`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`；签名密钥必须妥善备份且以后不可更换，否则 Android 会拒绝覆盖更新。切换当前 debug 测试版至正式签名版时需先卸载测试版一次；此后正式版之间可直接覆盖更新。数据保存在服务器，不会因卸载 App 而丢失。

## 权限和数据可见范围

- 同学只能读取整体已发布排班、本人空闲报名和本人请假/补班申请。
- 同学端不提供其他成员的报名、审批队列、请假补班详情或操作动态接口。
- 管理员可以查看报名、管理成员、编排/发布排班、审批申请并查看操作记录。
- 请假获批后，从对应班次移除申请人；补班获批后，将申请人加入对应班次。技师固定占首位；无技师时首位留空，其余位置最多安排 4 人。
- 每天安排下午班（16:30–18:30）和晚班（18:30–20:30），每班 2 小时。报名可选择本周或下周，默认打开本周；升级时会校正空白周次，或调整有数据周次的时段并保留原成员、报名、申请与排班关联。
- 普通成员查看排班时，自己的名字以加粗红色底纹标出。
- 管理员可在手动编排中指定本班首位技师；其余正式技师按原有班次顺序排在实习/普通成员之前。自动排班、成员技师身份变更和请假补班审批均保持该排序。
- 管理员周次选择器会列出有过报名或发布记录的历史周次，并可查看、编辑和重新发布；普通成员只可查看本周和下周。
- 报名默认在排班周开始前一天 20:00 截止（例如周一 10 月 5 日开始，则周日 10 月 4 日 20:00 截止）；当前周和下周的截止时间会按此规则自动校正。
- 期望值班次数可设为 0。自动排班按报名可用时段分配：正式技师优先排在首位，其余成员按期望次数比例均衡安排。

所有页面数据来自服务端数据库，不依赖浏览器 localStorage。登录使用 HttpOnly 会话 Cookie，密码使用 scrypt 哈希保存。此版本不接入打卡设备，也没有迟到统计和推送通知；服务目前通过 30 秒轮询刷新页面数据。

## 当前范围

已包含首次管理员初始化、管理员/同学账号登录、周次和班次创建、空闲报名、自动及手动排班、排班发布、请假/补班审批、成员账号管理、管理员操作记录以及 CSV 排班导出。网页采用手机底部导航和桌面侧边栏两种布局。
