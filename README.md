# 铁马驿站排班中心

铁马驿站排班与考勤管理网页的第一版交互原型，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 本地预览

直接打开 `index.html`，或从此目录启动一个静态文件服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前体验功能

- 管理员与普通同学视角切换
- 周排班表浏览、排班建议和发布操作反馈
- 下周空闲时间选择与期望班次提交
- 请假、换班、补班申请提交和管理员审批
- 打卡记录查看、统计和 CSV 导出
- 移动端布局
- 申请与报名数据保存在当前浏览器的 `localStorage`

页面中的人员、班次和打卡记录均为演示数据。管理员身份切换仅用于界面预览，不构成真实权限控制。

## 后续接入

要投入真实使用，需要补充服务端 API、数据库、真实登录与角色鉴权、通知服务、审批审计记录，以及打卡设备适配器。建议先确认打卡器品牌、型号、接口文档和人员编号映射方式，再实现实时 API 或定时同步；若设备不提供接口，可先支持表格导入。
