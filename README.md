# 铁马驿站排班中心

手机优先的排班与请假补班网页。页面和 API 由同一个 Node.js 服务提供，SQLite 保存账号、报名、排班、审批和管理员操作记录。无需 npm 安装第三方依赖。

## 本机启动

需要 Node.js 22.13 或更新版本。PowerShell 中运行：

```powershell
cd iron-horse-web
npm start
```

打开 `http://localhost:3000`。首次打开会要求创建唯一的管理员账号；管理员随后可以在“成员管理”中创建同学账号。数据库会自动写入 `data/iron-horse.sqlite`。

停止服务按 `Ctrl+C`。数据库文件应定期备份；备份时先停止服务，再复制 `data/iron-horse.sqlite`。

## 手机和多人访问

在同一个 Wi-Fi/局域网内，可以在运行服务的电脑上查看本机 IP（PowerShell 执行 `ipconfig`），然后让手机访问 `http://电脑的局域网 IP:3000`。服务必须保持运行，电脑和手机需要能互相访问；Windows 防火墙可能需要允许 Node.js 接收局域网连接。

跨校区或互联网访问需要一台持续在线、能被用户访问的服务器，通常配置域名和 HTTPS。部署在 HTTPS 反向代理后，启动前设置 `COOKIE_SECURE=1`；可用 `PORT` 指定监听端口，`DB_PATH` 指定数据库文件位置。SQLite 适合当前小规模单服务使用；如果以后需要多实例、高并发或托管数据库，可迁移到 PostgreSQL。

## 权限和数据可见范围

- 同学只能读取整体已发布排班、本人空闲报名和本人请假/补班申请。
- 同学端不提供其他成员的报名、审批队列、请假补班详情或操作动态接口。
- 管理员可以查看报名、管理成员、编排/发布排班、审批申请并查看操作记录。
- 请假获批后，从对应班次移除申请人；补班获批后，将申请人加入对应班次。每班最多 5 人。
- 自动排班优先安排已报名的正式技师，并尽量避免同一人同日连续班次。

所有页面数据来自服务端数据库，不依赖浏览器 localStorage。登录使用 HttpOnly 会话 Cookie，密码使用 scrypt 哈希保存。此版本不接入打卡设备，也没有迟到统计和推送通知；服务目前通过 30 秒轮询刷新页面数据。

## 当前范围

已包含首次管理员初始化、管理员/同学账号登录、周次和班次创建、空闲报名、自动及手动排班、排班发布、请假/补班审批、成员账号管理、管理员操作记录以及 CSV 排班导出。网页采用手机底部导航和桌面侧边栏两种布局。
